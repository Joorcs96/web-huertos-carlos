⏰ Horarios y Automatizaciones Activas

Los programas automáticos activan el riego a las horas programadas siempre que la humedad del suelo esté por debajo del umbral óptimo y el depósito tenga nivel seguro.

🛡️ Seguridad de Riego Inteligente

  • Corte por Depósito Bajo: El sistema suspende los riegos automáticos si el agua baja del 15% para proteger las bombas.
  • Temporizador de Respaldo Físico: Las electroválvulas tienen un apagado máximo de seguridad (20 min) en caso de fallo de red.
  • Modo Lluvia: Se desactiva el riego si el higrómetro detecta saturación o lluvia reciente.
  • Control Horario Nocturno: Prioriza las horas de menor evaporación (amanecer y anochecer) para ahorrar agua.

🔌 Guía de Hardware y Sensores

Para conectar el huerto físico de Carlos con la web, el proyecto incluye el firmware listo para flashear en un ESP32 en la carpeta hardware/esp32_huerto_carlos.ino.

• ESP32 NodeMCU / WROOM-32
• 4x Sensores capacitivos de humedad v1.2
• 1x Módulo 4 Relés 5V (electroválvulas 12V/24V)
• 1x Sensor DHT22 / BME280 (Temp/Humedad)
• 1x Sensor ultrasonidos HC-SR04 (Nivel depósito)
